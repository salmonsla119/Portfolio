# 김채연 포트폴리오 HTML

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

## 내용 수정

- 주요 콘텐츠와 목록: `assets/data.js`
- 자세한 한국어 수정 안내: `편집방법.md`
- 게임은 `games` 배열을 복제해 30개 이상 추가할 수 있으며 필터가 자동 생성됩니다.
- 대표 프로젝트는 `projects`의 첫 항목입니다. `image`에 이미지 경로를 입력합니다. 목록에서 크게 강조하고 싶은 프로젝트에는 `featured:true`를 추가합니다.
- 플레이 장르 순위와 육각형 그래프는 `games`의 `genre`를 자동 집계하며, 등록 수가 많은 상위 6개 장르가 그래프에 표시됩니다.
- 프로젝트 상세 페이지: `team`에 파트·인원, `shortVideos`에 `{src:"영상 경로"}`, `images`에 `{src:"이미지 경로", alt:"설명", caption:"캡션"}`, `documents`에 `{title:"기획서명", src:"파일 경로"}` 형식으로 여러 개 추가합니다.
- 이력서: `resume.html`, 자기소개서: `assets/data.js`의 `coverLetter` 항목 (마크다운 문법으로 작성하면 `cover-letter.html`에 그대로 서식이 적용되어 표시됩니다)
- 색상 및 반응형 디자인: `assets/style.css` (맨 위 `:root`의 색상 변수만 바꾸면 전체 페이지 색이 함께 바뀝니다)
- 달·반짝이 등 도트 아이콘은 HTML 안에 들어 있는 픽셀 SVG입니다. 자세한 수정법은 `편집방법.md` 참고.

기술 게이지 값은 0~100입니다. 플레이 장르 그래프와 막대는 게임 목록의 장르별 등록 개수로 자동 계산됩니다.
