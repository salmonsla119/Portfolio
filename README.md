# 김채연 포트폴리오

게임 기획자 김채연의 포트폴리오 사이트입니다.

- 공개 주소: https://salmonsla119.github.io/Portfolio/
- 설치나 빌드가 필요 없습니다. `index.html`을 브라우저에서 열면 됩니다.

## 내용 수정

- 주요 콘텐츠: `assets/data.js`
- 한국어 편집 안내: `편집방법.md`
- 색상: `assets/style.css` 맨 위 `:root`

## 브랜치

- `main` — 현재 디자인. 올리면 공개 주소에 자동 반영됩니다.
- `design-v1` — 크림색·남색 도트 디자인(이전 버전) 보존용
